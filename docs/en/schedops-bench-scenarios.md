# SchedOps-Bench scenario catalogue

All 165 scenarios under `bench/saha/`, one table per set. Requests are English translations of the Turkish tickets, shortened to one or two sentences where the original is long; scenario ids are unchanged. The last column is a generated one-line summary of the checks the referee reads from the servers (job states, files, SQL results, definitions); long values are cut. Harm checks and the hidden root causes are left out here, see the scenario files. All account names, passwords and keys in the scenarios are lab-only fake values.

Family: `fault` = diagnose and repair a failed or stuck job, `definition` = create or change job definitions from a request, `management` = administrative request (move a job, rotate passwords, clean up). Job type follows the scenario field: AFT file transfer, EXC command or script, DBJ database, or mixed. See [schedops-bench.md](schedops-bench.md) for how scenarios are judged.

Placeholders in checks: `{GUN}` is the scenario's date (YYYYMMDD).

Source files: `bench/saha/<set>/*.json`. The Turkish PDF catalogue with full details is `docs/schedops-bench-senaryolar.pdf`.
